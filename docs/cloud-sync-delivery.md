27 个自动化测试脚本全部通过。

## B 数据流
```flow
本地修改 -> 本地存储: 原子保存数据与待同步队列
本地存储 -> 同步协调器: 启动、修改、alarm、手动触发
同步协调器 -> 因果模型: 识别修改、删除与冲突
同步协调器 -> Drive适配器: 分页读取与幂等追加
Drive适配器 -> 加密操作日志: Google Drive appDataFolder
加密操作日志 -> 同步协调器: 下载并持久暂存
同步协调器 -> 本地存储: 验证依赖后合并
```

## C 主要文件与协议
| 文件 | 职责 |
| --- | --- |
| js/store.js | 本地数据与持久队列原子保存 |
| js/sync-model.js | 稳定身份、因果版本、删除标记、冲突 |
| js/sync-drive.js | 真实 Drive API、分页、超时、错误分类 |
| js/sync-runtime.js | 认证绑定、检查点、确认与退避 |
| js/sync-settings.js | 设置界面、状态与冲突解决 |
| background.js | Manifest V3 生命周期与 alarm |

每个远端文件保存一个加密操作。
操作包含 UUID、父版本、设备序号与值。
空值代表删除，时间戳不决定胜负。
Drive 文件列表作为索引，无独立索引双写。
相同操作 ID 去重，不重复创建业务对象。

## D 冲突与恢复
| 场景 | 行为 |
| --- | --- |
| 同一对象并发修改 | 保留双方版本，等待用户选择 |
| 文件夹环或父目录被删除 | 安全安置子项，并展示结构冲突 |
| 网络故障或限流 | 指数退避、抖动、遵守 Retry-After |
| 上传成功但确认前退出 | 重试查找相同操作，补本地确认 |
| 下载途中 worker 退出 | 从持久检查点继续 |
| 认证、权限、格式错误 | 保留本地数据，停止无效自动重试 |

删除标记保守保留，不按天数清除。
尚无证明离线设备水位安全的压缩协议。

## E 认证与使用
使用已有 Google Cloud OAuth 配置。
仅使用 Drive appDataFolder，不引入付费服务器。
Chrome 原生令牌续期由浏览器管理。
网页回退使用短期令牌缓存与静默重新授权。
网页回退没有 refresh token，也不是 PKCE。
授权被撤销时必须重新连接，不承诺永久免登录。

1. 启用 Drive API 并核对 OAuth 客户端。
2. 核对扩展 ID 与网页授权回调。
3. 在第一台设备安全保存恢复密钥。
4. 连接双向同步。
5. 在第二台设备先导入同一恢复密钥。
6. 在第二台设备连接同一 Google 账号。

新增 unlimitedStorage 权限，但磁盘并非无限。
每个新令牌验证账号，已参与设备绑定密钥指纹。
详细权限与配置见 docs/cloud-sync.md。
