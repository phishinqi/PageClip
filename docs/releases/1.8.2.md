# PageClip 1.8.2

- 云端功能简化为单一 Google Drive 自动加密备份区域，保留手动备份、恢复、历史备份及加密恢复密钥管理。
- 新增发布者托管的 Cloudflare Worker + D1 Google Web OAuth：统一 HTTPS 回调，刷新令牌加密保存在后端，扩展直接访问 Drive。
- 授权回调完成后立即领取连接凭据；返回页面、窗口聚焦和持久状态变化及时更新账号与备份状态。
- 修复 Cloudflare workerd 不支持 `redirect: error` 导致的换码失败，显式拒绝服务端重定向。
- 双向同步界面和后台运行入口已停用；已有本地数据、同步历史、待处理记录和远端日志保留。

验证：32 个扩展回归脚本、17 个 Worker 测试通过；语法/JSON、国际化检查通过。Ego 真实 Google 授权成功，页面和后台停用迁移已实测。

限制：Brave、Edge、Firefox 的真实授权及长期令牌刷新仍需单独验收。自动备份不是实时双向同步；其他设备恢复需要相应密码或同一恢复密钥。授权可能被 Google 撤销，不保证永久免登录。Cloudflare 部署与安全说明见 `oauth-worker/README.md`。

发布附件：`PageClip-v1.8.2.zip` 为商店提交包（不含开发身份 key）；`PageClip-v1.8.2-unpacked.zip` 供解压加载，保留公开 manifest key 以维持认证服务白名单中的扩展 ID。公开 key 不是私钥。当前环境没有 CRX 签名私钥，本次不提供签名 CRX。未自动提交 Chrome Web Store。
