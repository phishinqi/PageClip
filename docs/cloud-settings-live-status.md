# Google Drive settings consolidation and live status

- One `#cloud-settings-card` inside the Backup & data settings section. The existing `#sync-settings` node is moved into it; it is never cloned. Account authorization has one controls area; full backup and two-way sync have distinct operation status. The sync enable button is gated by connected account state.
- `background.js` resumes durable broker authorization immediately after the exact configured HTTPS callback finishes loading. Singleflight coalesces overlapping callbacks, alarms and trusted `auth-resume` messages. Alarms remain recovery fallback. Backup-only authorization does not enable sync.
- `options.js` observes relevant local storage key names, visibility and focus; reads persisted account/backup state without fetching Drive or renewing tokens during polling. A 15-second visible-page fallback catches missed events. Focus can request durable authorization resume.
- `js/settings-status-refresh.js` coalesces event bursts, invalidates in-flight stale reads, skips hidden pages and recovers on subsequent requests after failure. Only changed cloud controls are replaced; unrelated settings, dialogs, drafts, sync listeners and conflict details are preserved.
- Manual backup shows preparation/upload progress and disables duplicate actions until completion. Success time is taken from the saved backup acknowledgment, not inferred from authorization or local save.
