PageClip 隐私政策
Privacy Policy

生效日期 / Effective date: 2026-08-29
最后更新 / Last updated: 2026-08-29

PageClip 是本地优先的 Chrome 扩展。Google Drive 云备份只有在用户主动操作时才发生，上传前在本地完成加密。

1. 我们处理什么数据 / What data is processed

PageClip 在本地处理用户主动保存的网页信息，包括 URL、标题、favicon 地址、文件夹、标签、备注、创建时间、置顶状态、快捷收藏夹、标签集合、Inbox、已读状态、回收站快照和应用设置。

PageClip processes web page URLs, titles, favicon URLs, folders, tags, notes, timestamps, pinned state, quick-access items, tab groups, Inbox entries, read state, recycle-bin snapshots, and application settings that the user chooses to save.

2. 本机存储 / Local storage

永久收藏、快捷收藏夹、Inbox、回收站和设置默认保存在当前浏览器的 chrome.storage.local。本机密钥模式使用浏览器 IndexedDB 保存本机加密密钥。

PageClip does not operate a separate application server and does not send local data anywhere unless the user explicitly starts a supported export or cloud backup action.

3. Chrome 权限 / Chrome permissions

  • bookmarks：浏览和管理 Chrome 原生书签；浏览器书签导入是复制操作，不修改原书签。
  • tabs：读取当前页面或当前窗口标签页的 URL、标题和 favicon 信息。
  • storage：保存 PageClip 本地数据。
  • favicon：显示网页图标。
  • contextMenus：提供右键快捷操作。
  • tabGroups：保存标签集合中的标签组信息。
  • scripting：在普通网页中显示 PageClip 网页侧栏入口。
  • identity / identity.email：连接并显示用户选择的 Google 账号。
  • readingList（可选）：在用户授权后读取、添加、标记或删除 Chrome Reading List 条目。

4. Google OAuth 与 Drive / Google OAuth and Drive

用户主动连接 Google Drive 后，PageClip 使用 Google OAuth 访问该用户的 Google Drive 应用数据目录 appDataFolder。只保存一个名为 PageClip-latest.enc 的最新备份文件。

When enabled, PageClip uses Google OAuth to access the user's application data folder in Google Drive. The uploaded file is encrypted before upload and contains no plaintext PageClip collection data.

PageClip does not upload the backup password, raw device key, access token, advertising identifier, analytics identifier, or browsing history unrelated to data selected for backup.

5. 加密 / Encryption

备份密码模式使用用户每次输入的密码派生加密密钥；密码不会保存。Chrome 本机密钥模式使用本机加密密钥；跨设备恢复需要用户导入由单独恢复密码保护的恢复密钥文件。

如果用户忘记备份密码且没有可用恢复密钥，PageClip 无法解密备份。PageClip 不承诺能够恢复丢失的密码、恢复密钥或第三方服务中的数据。

6. 第三方服务 / Third-party services

PageClip 依赖 Chrome、Google Drive 和 GitHub 等第三方服务。Google 账号、Drive、Chrome Web Store 和 GitHub 的使用分别受其自身隐私政策和服务条款约束。

7. 数据保留与删除 / Retention and deletion

本机数据由用户在扩展中删除，或由用户卸载扩展。云端备份由用户通过 PageClip 的退出、重新备份或 Google 账号相关管理操作控制。PageClip 不会在后台自动上传或建立用户数据副本。

如需提交隐私问题、数据删除请求或安全报告，请通过 GitHub Issues 联系。不要在公开 Issue 中提交备份密码、恢复密钥、OAuth Token 或私人收藏内容。

8. 儿童隐私 / Children

PageClip 不是面向儿童设计的服务，我们不会故意收集儿童个人信息。

9. 政策变更 / Changes

隐私政策发生实质变化时，会在本页面更新最后修改日期。继续使用更新后的 PageClip 表示你已阅读更新内容。

10. 联系方式 / Contact

隐私相关联系渠道：https://github.com/phishinqi/PageClip/issues
