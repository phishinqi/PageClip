LOCAL-FIRST BROWSER WORKFLOW

把网页，收进
自己的工作流。

PageClip 是一个本地优先的 Chrome 扩展：收藏网页、整理标签和文件夹、暂存 Inbox、保存标签集合，并在需要时用客户端加密备份到 Google Drive。

Chrome Web Store · 即将上线查看 GitHub 源码

PageClip currently ships as a local-first Chrome extension. Chrome Web Store listing is coming soon.

FEATURES / 功能

轻量，但不简陋。

Keep the browser as your workspace without forcing your bookmarks, reading queue, and temporary tabs into one indistinguishable pile.

永久收藏

标签、备注、嵌套文件夹、置顶、自定义排序和全局搜索，管理真正想留下的内容。

快捷收藏夹

保存单页或当前窗口标签集合，集合可改名、排序、删除网页并恢复到当前窗口。

Inbox / 稍后阅读

PageClip Inbox 与 Chrome Reading List 分开管理，删除和完成操作可通过 30 天回收站撤销。

Chrome 书签

只读导入浏览器书签树，保留根目录和嵌套结构，不改变 Chrome 原生书签。

加密云备份

手动选择备份密码或本机密钥，客户端 AES-GCM 加密后才上传 Google Drive。

本地优先

没有广告、分析脚本或自建服务器；本地数据保存在浏览器，需要时再由你手动备份。

SECURITY / 安全

上传的是密文，不是收藏。

Encrypted before upload

  • AES-256-GCM 客户端加密。
  • 备份密码不会被保存或上传。
  • 本机密钥可导出为加密恢复文件。
  • Google Drive 只保存单个最新密文备份。

透明的权限边界

  • Chrome 书签只在相关功能执行时读取。
  • Chrome 原生书签不纳入云恢复。
  • 不使用行为追踪、广告或用户画像。
  • 隐私政策完整列出权限和数据用途。
